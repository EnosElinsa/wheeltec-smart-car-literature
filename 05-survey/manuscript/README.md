# Wheeled mobile robot autonomy under degradation

Working survey draft: *Wheeled Mobile Robot Autonomy Under Degradation: A Survey of Methods and Evaluation*.

[Main paper](survey.pdf) · [Supplement](supplement.pdf) · [Revision status](REVISION-REPORT.md) · [Evidence library](../../README.md)

The current paper compares 229 selected publications (228 technical and one context review) with 5 additional background references, for 234 references, all from 2021-2026. It compares degradation responses across estimation, planning, semantic navigation, coordination and reliability. Assessment depth and non-exhaustive selection are disclosed in the supplement. N01–N20, S01–S48 and R01–R36 are integrated into the technical comparisons, evaluation discussion and open questions; the S and R cards are targeted readings, not whole-paper audits. X01/X15 remain internal library sources.

The main paper has 24 pages, the T-IV maximum, and the supplement eight. [EVIDENCE-MAP-AND-PROSE.md](revision/EVIDENCE-MAP-AND-PROSE.md) records the current revision: Table IV as an evidence map generated from the corpus coding, its findings in the text and the restructured prose. [PAGE-LIMIT-AND-FIGURE-STYLE.md](revision/PAGE-LIMIT-AND-FIGURE-STYLE.md) records the module tables moved to the supplement, the synthesis table and the grayscale figures, and [FIGURES-AND-CONDENSATION.md](revision/FIGURES-AND-CONDENSATION.md) the SVG figures, condensed sections, the shorter Section III and reference formatting.

This directory is part of the evidence-library repository, which is the project's only repository. The manuscript was a separate Git repository until November 4, 2026. That repository has been deleted from GitHub, and its history is kept in a local backup bundle.

## Build

The committed sources, figures and generated tables compile with TeX Live or MiKTeX, IEEEtran, graphicx, xr and BibTeX. The main paper cites the supplement tables through `xr`, so compile the supplement first:

```shell
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error supplement.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error -file-line-error survey.tex
```

## Figures

`figures/*.svg` are the editable figure sources and `figures/*.pdf` the vector files that LaTeX includes. The figures are grayscale with Times text, matching the IEEEtran body font. Both file types are generated by one script, which needs Python 3.10+ and PyMuPDF (`pip install pymupdf`):

```shell
python scripts/build_figures.py
```

`scripts/svgkit.py` holds the drawing helpers. The corpus figure of the supplement reads `generated/corpus-year-module.json`, written by `scripts/build_data.py`. PyMuPDF ignores SVG dash arrays and markers, so the helpers draw dashes and arrowheads as explicit segments and polygons.

## Regenerate and verify

Python 3.10+ is needed for the scripts. They locate the evidence library two levels up (the repository root); set `WHEELTEC_LITERATURE_ROOT` to use another checkout.

```shell
python scripts/build_data.py
python scripts/verify_delivery.py
```

The verifier requires successful builds and `pdfinfo` on PATH. Its default mode checks public corpus data, citations, labels, equations, generated quantities and PDF diagnostics, and records the repository commit the checked tree is based on. To additionally verify all 693 source artifacts, restore the local PDFs/transcriptions at their indexed paths and run:

```shell
python scripts/verify_delivery.py --sources
```

The public library excludes publisher full texts. Missing local sources must not be interpreted as completed source verification. Original publisher citations are retained in the library; `refs.bib` is the manuscript's derived bibliography, in which `scripts/bib_case.py` brace-protects acronyms and proper names in titles for IEEEtran sentence case. `ieee-bst-control.bib` applies the IEEE rule of listing the first author and "et al." for entries with more than six authors. Numerical comparison locators and source hashes are in `data/`.
