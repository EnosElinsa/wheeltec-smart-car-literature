# Survey manuscript

*Wheeled Mobile Robot Autonomy Under Degradation: A Survey of Methods and Evaluation* is maintained in [wheeltec-navigation-survey](https://github.com/EnosElinsa/wheeltec-navigation-survey).

The manuscript repository contains the main paper, supplement, LaTeX sources, generated tables, bibliography, numerical evidence records and build instructions. It is a working draft with author information and submission declarations still to be completed. The current main paper has 27 pages and 163 references; its three-page supplement records selection and evaluation details.

The local checkout is `manuscript/`, a separate Git repository excluded from this evidence library. The public manuscript snapshot is explicitly authorized by the owner. Publisher PDFs and transcriptions remain local.
