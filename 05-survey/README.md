# Survey manuscript

*Wheeled Mobile Robot Autonomy Under Degradation: A Survey of Methods and Evaluation* is maintained in [wheeltec-navigation-survey](https://github.com/EnosElinsa/wheeltec-navigation-survey).

The manuscript repository contains the main paper, supplement, LaTeX sources, generated tables, bibliography, numerical evidence records and build instructions. It is a working draft with author information and submission declarations still to be completed. The current main paper has 36 pages and 234 references, all from 2021-2026; its three-page supplement records selection and evaluation details.

The local checkout is `manuscript/`, a separate Git repository excluded from this evidence library. The public manuscript snapshot is explicitly authorized by the owner. Publisher PDFs and transcriptions remain local.

All 229 selected works appear in substantive prose, including the 36 papers of the [IEEE refresh](../06-data/ieee-refresh-2026-11-03/README.md). The [refresh integration analysis](../04-analysis/ieee-refresh-integration-2026-11-03.md) records the survey review findings, the removal of the five pre-2021 foundational references, and the open length and sentence-rhythm issues. The main paper exceeds the 24-page maximum of IEEE T-IV surveys, so a length decision is still required before submission. New cards are targeted light readings, not whole-paper audits.
