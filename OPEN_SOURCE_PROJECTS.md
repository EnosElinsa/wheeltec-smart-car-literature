# Open-source robotics projects

66 projects across six application areas, including 17 projects with deep reinforcement learning methods. 52 distinct publications link to reading files in the paper catalog. Project and publication counts are separate; multiple projects can cite the same paper.

[Browse and compare projects](INDEX.html#view=projects) · [Paper catalog](INDEX.html) · [Library guide](README.md) · [Data and interface guide](06-data/index-interface.md)

Search by project, algorithm or publication; filter by task, method, implementation environment and publication year. Compare up to four projects by algorithm, observations, outputs and R680 adaptation. The standalone HTML includes all project data and works without the textbook checkout or a server.

Algorithms, runtime notes and platform limits are maintained in [open-source-projects.json](06-data/open-source-projects.json). The directory was adapted from [textbook chapter 54](https://enoselinsa.github.io/wheeltec-ros-textbook/08-advanced-applications/54-open-source-projects/). Repository metadata is a dated GitHub snapshot; missing license metadata is left blank. A ROS 2 tag identifies an available implementation or linked integration; the detailed notes distinguish Humble, Foxy, Jazzy and Kilted. It does not establish R680 compatibility. Third-party code retains its own license.
